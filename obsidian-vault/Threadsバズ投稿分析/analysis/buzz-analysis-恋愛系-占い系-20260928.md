# buzz-analysis: 恋愛系・占い系 トップ50

[[../index|← インデックスに戻る]]

anthropic-skills:buzz-analysis スキルの型に沿って、澪（深夜の恋愛占い相談室）のコンテンツ設計のために恋愛系・占い系のいいね数トップ50を分析。全704件/558件を人手で意味分類するのは非現実的なため、**上位50件のみ**を対象にした（件数が少ないため「この50件では」という前提で読むこと）。

## 占い系（n=50）

```
■ フック型TOP3（件数）
1. 開運日型（日付×条件＋いいねで運気上昇）: 20件（40%）／代表例「明日は超大開運日ですね」
2. 実話・エピソード型: 7件／代表例「さっきDAISOで」
3. あるある型（日常・星座占い引用）: 5件

■ フック型TOP3（いいね数中央値）
1. 実話・エピソード型: 中央値 9,351
2. 思い込み型（引き寄せ・言い換え）: 中央値 7,567
3. あるある型: 中央値 6,142
※開運日型は件数最多だが中央値は最下位グループ（約6,000）。
 件数トップ＝伸びる型ではない、というズレが最大の発見。

■ 投稿構造TOP3
1. 一言断言型（開運宣言・格言）: 約25件
2. ストーリー型（実話エピソード）: 約9件
3. 箇条書き型: 約3件

■ 伸びている文字数レンジ
50〜250字（開運日型は短文、実話エピソード型は150〜300字とやや長め）

■ バズ要因まとめ
- 最も多い感情トリガー：希望（開運日型）／驚き（実話エピソード型）
- 実用性：低（開運日型はほぼ実用性ゼロ、いいね誘導のみ）
- 意外性：実話エピソード型に集中（「なんと」の展開）
- 保存動機：低い（保存より「いいね」を即時に押させる設計が主）

■ 重大な注意点：コピペ・使い回しの多さ
トップ50中、明確な完全一致の重複が複数発見された：
- 「子供の頃から占い好きだった私♡」: 4件が完全同一文
- 「エネルギーに満ちた女の子は〜」: 2件が完全同一文
- 蓮司さんの自己紹介文: 2件が完全同一文
- 「残念ですが、ご縁のない方には〜」: 2件が完全同一文
- 「無理かどうかは、自分で決めればいい」: 2件が完全同一文
→ 占い系の「バズる型」は、複数アカウントによる同一文面の使い回しが常態化している可能性が高い。
  オリジナリティで差別化する意味が薄い一方、法的リスク（景品表示法・効果保証）は最も高いクラスタが最多数を占める。
```

## 恋愛系（n=50）

```
■ 投稿構造TOP3
1. ストーリー型（具体的エピソード）: 約28件／代表例「音信不通の理由が〜」
2. 一言断言型: 約15件／代表例「いやまじで夫婦仲いいとこって旦那がちゃんとしとるわ」
3. あるある型: 約4件

■ 伸びている文字数レンジ
80〜250字（会話文を含むストーリー型がボリュームゾーン）

■ バズ要因まとめ
- 最も多い感情トリガー：共感／怒り（理不尽な相手に対する同意を誘う）
- 実用性：低〜中（教訓めいた投稿もあるが少数派）
- 意外性：高（「まさかの展開」「運命的な偶然」の構成が多い）
- 保存動機：中
- 共通する特徴：具体的な時刻・場所・会話文をそのまま提示し、
  最後は「教訓」ではなく「ツッコミ・余韻」で終える投稿が支配的。
  自己啓発的な"気づきの一文"で締める投稿はトップ50にほぼ存在しない。
```

## 次の打ち手

- 開運日型（件数最多・中央値最弱・法的リスク最大・コピペ横行）を澪の主力型にするのは避ける。
- 恋愛系のストーリー型＋占い系の実話・エピソード型を軸に、「相談を受けたタロット師」という澪の立ち位置から具体的なエピソードを語る形に寄せる。
- 投稿作成は `/buzz-post-creator` またはこのファイルのテンプレートを直接使用。
